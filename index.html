설정

클라우드 동기화

여러 기기(PC·아이폰)에서 같은 데이터를 보려면, 모든 기기에 같은 동기화 코드를 입력하세요. 이후 입력하는 내용은 자동으로 저장·동기화됩니다.

되돌리기 (자동 백업)
하루에 한 번, 그리고 클라우드에서 불러오기 직전에 이 기기에 사본을 남깁니다. 내용이 갑자기 사라졌을 때 되돌릴 수 있습니다.

아이폰 «뒷면 탭»으로 포스트잇 열기

아래 주소를 복사해 단축어 앱 → URL 열기에 넣고, 설정 → 손쉬운 사용 → 터치 → 뒷면 탭에서 그 단축어를 지정하세요. 폰 뒷면을 두 번 두드리면 포스트잇이 열립니다.

네이버 지도 선택

지도 탭은 기본으로 OpenStreetMap을 씁니다. 네이버 클라우드 플랫폼에서 받은 Client ID를 넣으면 지도 배경이 네이버 지도로 바뀝니다(핀·목록은 그대로). 키가 없거나 인증에 실패하면 자동으로 OpenStreetMap으로 돌아갑니다.

발급 방법 (10분)
① console.ncloud.com 가입 → 결제수단(카드) 등록 (월 600만 건까지 무료라 개인용은 0원입니다)
② 콘솔 Services → Application Services → Maps → Application 등록
③ 서비스 선택에서 Dynamic Map 체크 (안 하면 429 오류) · 원하면 Geocoding 도 체크
④ Web 서비스 URL에 이 주소를 등록:
⑤ 발급된 Client ID를 위 칸에 붙여 넣고 저장 → 지도 탭에서 확인

문서 게시판 일정에 붙일 PDF

파일은 HMD에 담지 않고 깃허브 게시판에 올려 둔 문서의 주소만 일정에 붙입니다. 일정 옆 📎를 누르면 그 자리에서 PDF가 열립니다. 공개 저장소여야 목록을 읽고 볼 수 있습니다.

구글 캘린더 내보내기

자동 전송은 쓰지 않습니다. 아래 버튼을 누를 때만 구글 캘린더로 보냅니다.

방법 1 · 파일로 가져오기 설정 불필요
.ics 파일을 받아 구글 캘린더 > 설정 > 가져오기 및 내보내기에서 가져옵니다.
방법 2 · 버튼 한 번으로 바로 반영 최초 1회 설치
구글 Apps Script 웹앱을 한 번 만들어 두면, 아래 «구글 캘린더로 보내기»를 누를 때마다 일정이 캘린더에 반영됩니다. 이미 보낸 일정은 덮어쓰고, 앱에서 지운 일정은 캘린더에서도 지웁니다.
루틴은 구글이 쓰기를 차단하지 않도록 오늘·내일 이틀치만 등록합니다(다음 날 다시 누르면 하루치가 이어집니다). 바뀐 것이 없는 항목은 건너뛰므로 여러 번 눌러도 구글 호출이 늘어나지 않습니다.
